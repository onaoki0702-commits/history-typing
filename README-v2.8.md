# v2.8の使い方

`history-typing-v2.8.html`をダウンロードしてChrome・Edgeで開くと遊べます。画像・音・コードは内蔵されており、インストールや外部通信は不要です。

- カードバトル勝利：1vs1は100pt、2vs2は150pt、3vs3は200pt。
- チケット獲得チャンス：20%／30%／40%。当選すると3種類から1枚。
- 図鑑・時空召喚 → 「時空のかけら交換所」からチケットを交換。
- 時代を選び、出撃前に1種類・1枚を選択。「使わない」も選べます。
- ハート＋1は開始時、防壁は敵到達時に自動使用。時止めは戦闘画面のボタンで発動。
- 時止めと防壁は、発動しなければ消費されません。

## 記録を引き継ぐ

同じサイト・同じブラウザでは旧データをそのまま読み込みます。オフラインHTMLの名前・場所や端末が変わる場合は、旧版の図鑑でバックアップし、新版の図鑑で読み込んでください。今回の新チケットは旧データでは0枚から始まります。

## GitHub Pagesを同じURLで更新

1. 現在のゲームの図鑑から念のため記録をバックアップ。
2. `history-typing-v2.8-web.zip`を展開。
3. 外側のフォルダではなく、中の `index.html`、CSS、`js`、`assets`、`.nojekyll`を公開ルートへ配置。
4. コミットし、Pagesの更新完了後に再読み込み。

現在のURL：https://onaoki0702-commits.github.io/history-typing/

URLを変えなければ、配布済みQRコードもそのまま使えます。この納品では公開先を直接更新していません。

## 編集用ソース

`history-typing-v2.8-source.zip`に、元v2.7のHTML、編集ソース、検証スクリプト、結果、段階保存の記録を含めています。

- `python build.py`：単体HTMLを生成
- `python build.py --web`：静的Web版も生成
- `src/support-data.js`：チケット、報酬設定、セーブの拡張
- `src/support-ui.js`：報酬、交換所、出撃前選択、使用処理
- `REPORT-v2.8.md`：ご指定9項目の詳細報告

テスト用のPlaywright・Chromium・フォントは開発環境用です。ゲーム本体にこれらをインストールする必要はありません。
